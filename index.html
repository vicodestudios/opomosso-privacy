Política de Privacidad de OpoMosso

Última actualización: 03/06/2026

Esta Política de Privacidad describe cómo Víctor Granados Trias, actuando bajo el nombre comercial VicodeStudios trata la información de los usuarios de la aplicación OpoMosso, disponible para Android e iOS.

Si tienes cualquier pregunta sobre esta Política de Privacidad o deseas ejercer tus derechos sobre tus datos, puedes contactar con nosotros en: vicodestudios@gmail.com.

1. Responsable del tratamiento

Responsable: Víctor Granados Trias(VicodeStudios)
Aplicación: OpoMosso
Contacto: vicodestudios@gmail.com

2. Información que podemos recoger

OpoMosso puede recoger y tratar la siguiente información necesaria para el funcionamiento de la aplicación:

  • Datos de cuenta: nombre de usuario, identificador de usuario, rol de usuario y preferencia de recordar sesión.
  • Credenciales de acceso: la contraseña se utiliza para autenticar al usuario mediante Firebase Authentication. No se almacena en texto plano en la aplicación.
  • Datos de uso educativo: resultados de tests, número de respuestas correctas, incorrectas y no contestadas, puntuaciones, progreso, temas practicados, estadísticas y fecha de última actividad.
  • Datos de ranking: nombre de usuario, identificador de usuario, puntuaciones y estadísticas necesarias para mostrar clasificaciones dentro de la aplicación.
  • Imagen de perfil: si el usuario decide seleccionar una imagen, la aplicación puede guardar una referencia local a dicha imagen para mostrarla como perfil.
  • Identificador de dispositivo: la aplicación puede usar un identificador técnico del dispositivo para funciones de seguridad, control de sesión o limitación de acceso.
  • Datos técnicos: información necesaria para el funcionamiento de Firebase y la comunicación segura con los servicios de backend.

3. Finalidad del tratamiento

Utilizamos la información anterior para:

  • Crear y gestionar cuentas de usuario.
  • Permitir el inicio de sesión y cierre de sesión.
  • Guardar el progreso y estadísticas de los tests.
  • Mostrar rankings y resultados dentro de la aplicación.
  • Gestionar preferencias de sesión, como recordar usuario.
  • Permitir funciones relacionadas con perfil de usuario.
  • Proteger la seguridad de la aplicación y evitar usos indebidos.
  • Mejorar la estabilidad y funcionamiento del servicio.

4. Servicios de terceros

OpoMosso utiliza servicios de Google Firebase para funciones de autenticación, almacenamiento y sincronización de datos.

Firebase puede tratar datos técnicos y de uso necesarios para prestar sus servicios. Puedes consultar más información sobre Firebase y privacidad en:

  • https://firebase.google.com/support/privacy
  • https://policies.google.com/privacy

5. Base legal

Tratamos los datos del usuario sobre la base de:

  • La ejecución del servicio solicitado por el usuario.
  • El consentimiento del usuario cuando corresponde.
  • El interés legítimo en mantener la seguridad y correcto funcionamiento de la aplicación.
  • El cumplimiento de obligaciones legales aplicables, cuando proceda.

6. Conservación de los datos

Conservaremos los datos mientras la cuenta del usuario permanezca activa o mientras sean necesarios para prestar el servicio. El usuario puede solicitar la eliminación de sus datos contactando con nosotros en vicodestudios@gmail.com.

Una vez recibida una solicitud válida de eliminación, procederemos a borrar o anonimizar los datos asociados, salvo que exista una obligación legal que requiera conservarlos durante un periodo adicional.

7. Eliminación de cuenta y datos

Para solicitar la eliminación de una cuenta o de los datos asociados a OpoMosso, el usuario puede enviar un email a vicodestudios@gmail.com indicando:

  • Nombre de usuario.
  • Solicitud clara de eliminación de cuenta o datos.
  • Cualquier información necesaria para verificar la titularidad de la cuenta.

Atenderemos la solicitud en un plazo razonable conforme a la normativa aplicable.

8. Compartición de datos

No vendemos los datos personales de los usuarios. Podemos compartir datos únicamente cuando sea necesario para:

  • Prestar el servicio mediante proveedores técnicos, como Firebase.
  • Cumplir obligaciones legales.
  • Proteger nuestros derechos, usuarios o la seguridad de la aplicación.

9. Seguridad

Aplicamos medidas razonables para proteger la información de los usuarios. La aplicación utiliza comunicaciones cifradas y servicios de backend seguros para la autenticación y almacenamiento de datos.

No obstante, ningún sistema es completamente seguro, por lo que no podemos garantizar una seguridad absoluta.

10. Menores de edad

OpoMosso está dirigida a personas que preparan oposiciones o formación relacionada. No está dirigida específicamente a menores de 13 años. Si detectamos que se han recogido datos de un menor sin el consentimiento necesario, tomaremos medidas para eliminarlos.

11. Permisos de la aplicación

La aplicación puede solicitar acceso a archivos o imágenes únicamente cuando el usuario decide seleccionar contenido, por ejemplo para una imagen de perfil o para importar material compatible. Dicho acceso se utiliza solo para la finalidad seleccionada por el usuario.

12. Transferencias internacionales

Al utilizar servicios como Firebase, los datos pueden ser tratados en servidores ubicados fuera del país de residencia del usuario. En esos casos, se aplican las garantías ofrecidas por los proveedores correspondientes.

13. Cambios en esta Política de Privacidad

Podemos actualizar esta Política de Privacidad para reflejar cambios legales, técnicos o funcionales. Cuando se realicen cambios relevantes, actualizaremos la fecha indicada al inicio de este documento.
